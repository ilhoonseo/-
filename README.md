# 🐨 코알라 연산 캐치

배고픈 코알라를 움직여 **정답이 적힌 유칼립투스 잎**을 받아먹는 초등 수학 연산 연습 웹게임입니다.
설치 없이 `index.html` 파일 하나로 실행됩니다(외부 라이브러리 없음).

## 🎮 게임 방법
- 화면 위쪽에 문제가 나오고, 숫자가 적힌 잎들이 떨어집니다.
- 코알라를 움직여 **정답 잎**을 받아먹으세요.
  - ⌨️ PC: `←` `→` 또는 `A` `D` (일시정지: `P` / `Esc`)
  - 📱 태블릿·스마트폰: 화면을 터치하거나 드래그
- 오답을 먹거나 정답 잎을 놓치면 하트 ❤️ 가 줄어듭니다. 하트 3개가 모두 없어지면 게임 끝!
- 정답 5개마다 레벨이 오르고, 수의 범위가 넓어지며 잎이 빨라집니다.
- 연속으로 맞히면 콤보 보너스 점수를 받아요.
- 게임이 끝나면 **오답 노트**로 틀린 문제와 정답을 다시 확인할 수 있습니다.

## 📚 학습 모드
| 모드 | 내용 | 대상 |
|---|---|---|
| ➕ 덧셈 | 10 이내 → 20 → 50 → 100 이내 | 1~2학년 |
| ➖ 뺄셈 | 10 이내 → 20 → 50 → 100 이내 | 1~2학년 |
| ✖️ 곱셈구구 | 2·5단 → 2~5단 → 2~7단 → 2~9단 | 2학년 |
| ➗ 나눗셈 | 곱셈구구 범위의 나눗셈 | 3학년 |
| 🎲 섞어서 | 사칙연산 혼합 | 복습용 |
| ❓ 빈칸 채우기 | `3 + □ = 7` 처럼 □ 구하기 | 1~3학년 |

오답 보기는 정답 근처의 수(±1, ±2, ±10 등)로 만들어져 실수하기 쉬운 부분을 연습할 수 있습니다.
모드별 최고 점수는 브라우저(localStorage)에 저장됩니다.

## 🚀 배포 (GitHub Pages)
1. 이 저장소의 **Settings → Pages** 로 이동
2. **Source**: `Deploy from a branch`, **Branch**: 게임이 있는 브랜치 / `/(root)` 선택 후 Save
3. 잠시 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/` 주소로 접속 가능
4. 이 주소를 [코알라게임](https://coalagame.web.app/) 의 **게임 올리기** 버튼으로 제출

> 로컬에서 테스트하려면 `index.html` 을 브라우저로 바로 열면 됩니다.
