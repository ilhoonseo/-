# 🐨 코알라 퀴즈 캐치

배고픈 코알라를 움직여 **정답이 적힌 유칼립투스 잎**을 받아먹는 초등 교과 퀴즈 웹게임입니다.
**수학 · 국어 · 영어 · 상식 27가지 모드**와 **선생님이 직접 만드는 퀴즈**를 지원합니다.
설치도 외부 라이브러리도 필요 없는 순수 HTML/CSS/JavaScript라서 어디에나 올리면 바로 실행됩니다.

## 🎮 게임 방법
- 위쪽에 문제가 나오고, 답이 적힌 잎들이 떨어집니다. 코알라가 **정답 잎**을 먹게 해 주세요.
  - ⌨️ PC: `←` `→` 또는 `A` `D` · 일시정지 `P` / `Esc` · 시작 `Enter`
  - 📱 태블릿·스마트폰: 화면을 터치하거나 드래그
- 연속으로 맞히면 **콤보 보너스**, 정답 5개마다 **레벨 업**(문제가 어려워지고 잎이 빨라짐)
- 10문제마다 **👑 황금 보너스 문제**(점수 3배)
- 레벨이 오르면 배경이 아침 → 한낮 → 노을 → 밤으로 바뀝니다.
- 틀리거나 놓치면 정답 잎이 반짝이며 정답을 알려 주고, 게임이 끝나면 **📒 오답 노트**로 복습합니다.

### 아이템
| 아이템 | 효과 |
|---|---|
| ❤️ | 하트 +1 (타임어택은 +5초) |
| ⏳ | 6초 동안 잎이 천천히 |
| ⭐ | 8초 동안 점수 2배 |
| 🍀 | 오답 잎 하나 없애기 |
| 🐝 | 방해꾼! 부딪히면 어지러워요 (레벨 3부터) |

### 게임 방식
- **❤️ 기본**: 하트 3개. 틀리거나 정답을 놓치면 하트가 줄어요.
- **⏱ 타임어택**: 60초 동안 최대한 많이! 틀리면 3초 감소.
- **🐢 연습**: 느린 속도, 하트 무제한, 벌 없음. 일시정지에서 결과를 볼 수 있어요.

### 🏅 스티커북 & 기록
콤보, 점수, 레벨, 백발백중 등 **22가지 스티커**를 모을 수 있고, 모드별 최고 점수가 기기(브라우저)에 저장됩니다.

## 📚 학습 모드 (27가지)
| 과목 | 모드 |
|---|---|
| 🔢 수학 | 덧셈 · 뺄셈 · 곱셈구구 · 나눗셈 · 빈칸 채우기(□) · 섞어서 계산 · **시계 보기**(아날로그 시계 그림) · 단위 바꾸기 · 분수 · 도형 · 규칙 찾기 · 수 감각(짝·홀수, 자릿값, 크기 비교) |
| 📖 국어 | 맞춤법 · 반대말 · 높임말 · 속담 완성 · 초성 퀴즈 |
| 🔠 영어 | 영어 → 뜻 · 뜻 → 영어 · 대·소문자(b·d·p·q 헷갈림 연습) · 영어 숫자 · 영어 표현 |
| 🌏 상식 | 우리나라(역사·문화·기념일) · 세계 수도(국기) · 과학 퀴즈 · 곤충 찾기 · 안전 생활 |
| ✏️ 내 문제 | 선생님이 직접 만든 퀴즈 |

- 수학 문제는 레벨에 따라 수의 범위가 넓어집니다. (예: 덧셈 10 이내 → 20 → 50 → 100)
- 오답 보기는 **아이들이 실제로 자주 하는 실수**로 만들었습니다. (곱셈구구 이웃 단, 시계 긴바늘·짧은바늘 헷갈림, 단위 0 개수 등)

## ✏️ 선생님이 직접 퀴즈 만들기
1. 시작 화면에서 **✏️ 내 문제** 탭 → **문제 만들기**
2. 한 줄에 한 문제씩 적습니다.
   ```
   태양계에서 가장 큰 행성은? | 목성 | 토성, 화성, 지구
   7 × 8 = ? | 56 | 54, 48, 63
   우리나라의 수도는? | 서울
   ```
   - 형식: `문제 | 정답 | 오답, 오답, 오답`
   - 오답을 생략하면 다른 문제의 정답이 오답 보기로 나옵니다.
   - 엑셀·구글 시트에서 **문제 / 정답 / 오답** 열을 복사해 그대로 붙여 넣어도 됩니다(탭 구분 인식).
3. **🔗 공유 링크 만들기**를 누르면 문제가 담긴 링크가 복사됩니다. 학생들이 이 링크로 들어오면 같은 퀴즈를 바로 할 수 있어요. (서버 없이 링크 안에 문제가 들어 있습니다.)

## 🚀 배포 (GitHub Pages)
이 저장소는 `gh-pages` 브랜치로 배포됩니다. 게임을 수정한 뒤 `gh-pages` 브랜치에 푸시하면 1~2분 뒤 위 주소에 반영됩니다.

직접 설정하려면:
1. 이 저장소의 **Settings → Pages** 로 이동
2. **Source**: `Deploy from a branch`, **Branch**: 게임이 있는 브랜치 / `/(root)` 선택 후 Save
3. 잠시 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/` 주소로 접속
4. 이 주소를 [코알라게임](https://coalagame.web.app/) 의 **게임 올리기** 버튼으로 제출

> 로컬 테스트: `index.html` 을 브라우저로 바로 열면 됩니다.

## 📁 파일 구조
```

```

## 🛠 문제 추가·수정하기
`js/content.js` 의 목록에 한 줄만 추가하면 됩니다.
```js
// 과학 퀴즈에 문제 추가 (q: 문제, a: 정답, w: 오답)
{ q: "물이 끓는 온도는?", a: "100℃", w: ["0℃", "50℃", "10℃"] },

// 반대말 추가
["뜨겁다", "차갑다"],
```
새 모드는 `gen(lv)` 함수를 만들고 아래쪽 `subjects` 목록에 등록하면 메뉴에 자동으로 나타납니다.
